# Keepit — Data Inventory (internal, v3.5.161)

> Internal review file for the test ZIP. **Remove from public release copies.** Lists only data type, recipient, purpose and code location — no endpoints, payloads, tokens or internal logic.

## 2. Data kept only in the browser (not sent by Keepit)

Keepit bar preferences (hidden, compact, back-to-top, gesture switches, sites where page swipe is off, where the "Keepit is off" logo sits on the screen edge) and up to 6 recent bar searches in `lhnBottomBar`; the "Dark pages" switch (v3.5.207, on/off only, default off) in `lhnPageDark`, plus (v3.5.215, only while Dark pages is used) up to 200 host names of sites found to be dark already in `lhnPageDarkNative` (`js/background/background.js` `notePageDarkNative`, reported by `js/content/page-dark.js`) so they are not pre-darkened next time — host name only, no path or page content, never sent anywhere; the Keepit home page (v3.5.180, `pages/home.html`, `js/home/home-ui.js`) keeps its "More sites" shortcuts (name + address the user enters) in `lhnHomeBookmarks` and reads the last unfinished study session locally for its Continue learning card — no page or browsing history is read, nothing is sent; plus the first-run flag `touchBarIntroSeen` (`js/content/keepit-bar.js:817`, `js/content/keepit-bar.js:1196`); the bar search reads saved notes/highlights and dictation sessions locally only (`js/content/keepit-bar.js:832`). The offline page (v3.5.175, `js/content/offline-page.js`) reads up to 5 saved words locally while it is shown, for its review card; nothing is stored or sent. On touch, the page swipe asks the background for whether a previous/next tab exists in the same window and switches to it (`js/background/background.js:118`); only the tab order is read, nothing is stored or sent out. Highlights, notes, page title/URL of annotations, flashcards/study progress, settings, translation/TTS/transcript caches, URL → AI-conversation mapping (after a confirmed send), panel state, local usage counters, demo profile, diagnostic log (codes only). Favourite videos and web pages (video ID or page URL without fragment, title, channel or site name, time added; `js/overlay/overlay-engine.js:446`, `js/dashboard/dashboard.js:1162`, `js/dashboard/dashboard.js:1172`). Versions before v3.5.171 stored touch overlay view preferences (`lhnTouchOverlayCompact`, `lhnTouchOverlaySubHidden`); since v3.5.195 no code reads or writes them (values left by old versions stay in local storage and are removed by uninstalling). Unified overlay layout preferences (view per orientation, column widths, splitter, subtitle style/size/colours, repeat, study toggles such as hints/translation/auto-advance, export format) in `lhnOverlayUi`, local only (`js/overlay/ui/overlay-ui.js`, `OV_UI_KEY`); lesson notes, time-stamped notes and per-sentence scores of the unified Speak/Write tabs are saved inside the existing `dictation:<sourceId>` record (`lessonNote`, `notes`, `unifiedScores`). Favourite videos and pages (♥ in the video overlay — desktop control bar and touch — or double-tap): video ID or page URL, title, channel / site name and time added, in `lhnFavoriteVideos` (`js/overlay/overlay-engine.js:446`). Short speaking recordings stay in memory for playback only (`js/overlay/ui/overlay-ui.js:1713`). Favourite read-aloud voices (v3.5.232, ♡ in the Reader voice list): up to 50 browser voice IDs or `google:<language code>` entries, newest first, in `lhnSettings.favoriteVoices`, local only (`js/reader/tts-engine.js` `getFavoriteVoices`/`setFavoriteVoices`); nothing extra is sent — a favourite browser voice speaks on the device, a favourite Google voice uses the existing Google text-to-speech request (row 5).
